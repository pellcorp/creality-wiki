!!! info "Loadcells for Z-Offset"

    For K1, K1C, K1 Max, K1SE, Ender 3 V3, Ender 3 V3 SE and Ender 3 V3 KE users you have the option to use loadcells for automating
    your z-offset during printing.
    
    Just add `--loadcells-zoffset` to the installation command to enable the loadcells for z-offset.
    You can also pass this command by itself to enable loadcells for z-offset for an existing installation or as part of
    an update command to switch probes.
    
    See [Load Cells for Z-Offset](loadcells_zoffset.md).
